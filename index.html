Rules

1. Fill the white cells with numbers 1-9, ensuring each number appears once in each row and column.

2. Numbers in each white cell compartment must form a straight (consecutive sequence) in any order.

3. Black cells with numbers block that digit from appearing in that row and column.

Controls

1. Simply select a tile you want to edit with the mouse. You can also move your selection with the arrow keys.

2. Enter values via keyboard or by clicking on the numpad. By pressing the note icon or N you can also switch to note mode to write down multiple possible candidates.

3. The solver mode can give and apply hints for your current puzzle state if you are stuck. The creator mode allows you to build your own puzzle and provides a compact board representation for importing and exporting levels.
